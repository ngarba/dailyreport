
For the bar graphs:

Run dailybars30.py


Follow the prompts.

<img width="1094" height="212" alt="image" src="https://github.com/user-attachments/assets/8a4072de-40ff-4864-9765-d1ee96c30a55" />

If looking for only one activity, leave second activity prompt blank and hit Enter.

Note: Bar graphs cannot combine activities and conditions, so only use the activities prompts or the conditions prompts.

<img width="1090" height="134" alt="image" src="https://github.com/user-attachments/assets/f71354c2-ecb1-4e07-b260-d732570116fe" />

After activities, the conditions prompts will appear. In this case, since an activity was entered, the conditions are skipped.

<img width="1086" height="302" alt="image" src="https://github.com/user-attachments/assets/68985e90-4cab-409b-9193-cbe25b2985c2" />

Next, the script prompts for the name of a json file to be analyzed. If nothing is entered, a default set on line 55 is used.

<img width="810" height="52" alt="image" src="https://github.com/user-attachments/assets/f1ab38b5-4d65-475e-9b57-03f65442ba1d" />

The script confirms the entered json file.

<img width="463" height="44" alt="image" src="https://github.com/user-attachments/assets/a9298b51-c524-43ad-bd56-e37f1157dabc" />

Enter a first date. If left blank, it will add a default date that has been set on line 187.

<img width="798" height="143" alt="image" src="https://github.com/user-attachments/assets/bf292d0b-2144-4344-8f54-1733a13b9425" />

The script will display the entered date.

<img width="919" height="70" alt="image" src="https://github.com/user-attachments/assets/b9b94ec0-0b39-4ccf-b5a9-3610e0a6b2cf" />

Enter the last date. Like the first date, if left blank a default date will be entered. The default last date is on line 219.

<img width="713" height="66" alt="image" src="https://github.com/user-attachments/assets/2dfb6891-b67c-498b-b745-84e85c9b3636" />

Like the first date, the script will display the last date:

<img width="892" height="64" alt="image" src="https://github.com/user-attachments/assets/ab348ffd-e4e8-445c-b336-60f1d3ac8007" />

After this, a bar plot will appear, and inline of the script will provide the total time for the activity/condition and average time.

<img width="1119" height="1043" alt="image" src="https://github.com/user-attachments/assets/3abc19d9-a1b2-4e50-bca9-d0a363f66783" />

Hit the Save icon in the tool menu to save the plot.

<img width="48" height="54" alt="image" src="https://github.com/user-attachments/assets/a58b75b6-6da3-409c-bb40-115f54140804" />

Run dailypie30.py

The script prompts for the name of a json file to be analyzed. If nothing is entered, a default set on line 93 is used.

<img width="821" height="44" alt="image" src="https://github.com/user-attachments/assets/f8134a5a-ab86-4d99-b644-b00e1e037116" />

<img width="439" height="44" alt="image" src="https://github.com/user-attachments/assets/07ec6193-b216-48e3-8efe-b8a920b14f77" />

Follow the prompts. Enter the shortened abbreviation within the parentheses for the prompt, then hit Enter.

<img width="1661" height="175" alt="image" src="https://github.com/user-attachments/assets/38bb79fe-7b53-47a1-9d38-6bdcfb6fbe1f" />

Enter a first date. If left blank, it will add a default date that has been set on line 199.

<img width="798" height="143" alt="image" src="https://github.com/user-attachments/assets/bf292d0b-2144-4344-8f54-1733a13b9425" />

The script will display the entered date.

<img width="919" height="70" alt="image" src="https://github.com/user-attachments/assets/b9b94ec0-0b39-4ccf-b5a9-3610e0a6b2cf" />

Enter the last date. Like the first date, if left blank a default date will be entered. The default last date is on line 232.

<img width="713" height="66" alt="image" src="https://github.com/user-attachments/assets/2dfb6891-b67c-498b-b745-84e85c9b3636" />
